# Instructions for the coding AI

Follow this sequence.

## Stage 1 — Understand
Read:
- MASTER_PROMPT.md
- CONTENT.md
- ARCHITECTURE.md
- ACCEPTANCE_CRITERIA.md

Do not start coding before understanding all four.

## Stage 2 — Plan
Create:
- route map
- component map
- data model
- animation system
- responsive strategy

Then implement.

## Stage 3 — Foundation
Set up:
- Next.js
- TypeScript
- Tailwind
- Motion
- shadcn/ui where useful
- linting
- formatting

## Stage 4 — Design system
Create:
- colors
- typography
- spacing
- radii
- shadows
- animation primitives
- reusable cards/buttons

## Stage 5 — Build
Implement all required routes and shared components.

## Stage 6 — Interactions
Implement:
- domain search
- pricing toggle
- forms
- support search
- mobile navigation
- theme
- dashboard preview

## Stage 7 — Quality
Run:
- npm run lint
- npm run build
- tests

Fix issues rather than reporting them.

## Stage 8 — Final audit
Compare implementation against ACCEPTANCE_CRITERIA.md.

Do not say "complete" if major routes or requirements are missing.

Do not replace requirements with a simplified landing page.
